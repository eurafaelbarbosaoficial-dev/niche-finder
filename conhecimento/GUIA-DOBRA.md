# Guia da Dobra de Nicho — o método do Raj, organizado para virar sistema

Fonte: 28 vídeos do canal "Rhaj" (fev–nov/2026), legendas automáticas. Detalhes e minutos em `raj/notas.md`.
Aviso: os ganhos que ele cita são dele e dos alunos (propaganda do curso Dark Educação), não foram conferidos.
Ele mesmo conta que levou ~2 anos para monetizar o 1º canal (vídeo 24).

---

## 1. As peças de um canal (o vocabulário)

| Peça | O que é | Exemplo |
|---|---|---|
| **Macro / nicho** | o assunto | história, fitness, gatos |
| **Micro / formato** | COMO o vídeo é feito | catálogo sequencial, anatomia de avatar, POV/2ª pessoa, what-if, colagem em fundo branco, 2D animado |
| **Estrutura (molde) de título** | a frase com buracos | "Every [X] explained in [N] minutes", "What if [moderno] fought [antigo em massa]", "POV: sua vida como [cargo]" |
| **Formato de thumb** | a composição | grid 4+4, personagem + texto bold + fundo escuro, seta |
| **Tópico** | o assunto do vídeo | 2ª Guerra |
| **Tema** | a **pergunta emocional** por trás | "o que faz pessoas normais cometerem atrocidades?" |
| **Driver** | o gatilho que o tema ativa | curiosidade existencial, medo/ameaça, identidade/status, nostalgia/perda, injustiça/revolta, proibido |
| **Ângulo / promessa** | o jeito único de tratar o nicho | "elevação científica do banal", "completude", "verdades brutais" |
| **Barreira** | quão difícil é copiar | baixa (IA pura, imagem estática) · média (catálogo, manequim) · alta (3D, Kurzgesagt) |

**Regra mestra:** "domine o micro, troque o macro". O formato validado vai para outro nicho que tem demanda.

## 2. As 4 formas de dobrar (todas com exemplo real nos vídeos)

1. **Mesmo formato → outro nicho** (o preferido dele): catálogo de comida → mitologia, filosofia, civilizações.
2. **Mesmo formato + nicho → outro idioma**: Yellow Dude (EN) → Capitão Red (PT), versão japonesa.
3. **Mesmo formato + nicho → outro público**: fitness masculino → feminino; idosos (dor nas costas).
4. **Mesmo título/thumb → outro formato de conteúdo**: "Every UFC fighter" em colagem → em 2D animado
   (efeito UAU = quebra de expectativa).

E a pergunta que gera as dobras: **"Que outros universos posso apresentar dessa maneira?"**
(xadrez tático → futebol tático, futebol americano, basquete).

## 3. O processo de ponta a ponta

1. **Achar o outlier**: muitas views para poucos inscritos (ele usa views/vídeo ÷ inscritos ≥ 50×); ou um
   **cluster** = vários canais novos com o mesmo termo-chave e molde de título bombando juntos.
2. **Ranquear os vídeos do outlier** por views/dia; separar **TOP × FLOP**; descobrir os "filtros de performance"
   (o que os tops têm e os flops não — ex.: civilizações universalmente conhecidas × nichadas).
3. **Ficha DNA** do canal: macro, nicho, ângulo, promessa, formato, moldes de título, formato de thumb, estrutura de
   roteiro, personagem, cadência. Separar **visível** (copiável) de **invisível** (tema, roteiro, iteração).
4. **Gerar nichos candidatos** a partir do conceito (IA): "nichos que envolvam movimento/técnica/corpo…".
5. **Validar cada candidato** (ver seção 4) e ranquear.
6. **3 filtros finais** (se falhar em um, não começa):
   - **Estágio do formato** (E1 emergente → E2 cópias → E3 competição → E4 qualidade → E5 diferenciação →
     E6 maturidade → E7 saturação criativa → E8 super saturação). Entrar em E5 com jeito de E1 = fracasso.
   - **Nicho validado** (demanda + gap).
   - **Moat / fator UAU**: consigo ser incopiável? (views sem inscritos = commodity).
7. **Árvore editorial / calendário programático** (blocos temáticos, pilares) — nunca começar sem os próximos 20
   vídeos pensados.
8. **Executar 20 vídeos no mesmo nicho** antes de julgar; iterar com dados (48–72 h por vídeo).

## 4. Os testes de validação (juntando os vídeos 08, 19 e 25)

**Matriz de 6 eixos (0–5)** — vídeo 25: Demanda · Quantidade de assuntos · Every/All (compilável) · What if
(hipóteses) · Visual (dá thumb/cena) · Evergreen.

**Testes com nota 0–10** — vídeo 08:
- Já existe vídeo NESSE formato nesse nicho? (poucos = bom) · Views altas em vídeos ADJACENTES (outros formatos)? ·
  Qualidade dos existentes? · **Comentários pedindo mais?**
- Comunidades (Reddit/fóruns) ativas?
- CPM/RPM estimado e tier do nicho.
- Monetização extra (cursos, produtos, certificações).

**Tamanho do mercado** (vídeos 16 e 26): TAM (todos) → SAM (quem fala o idioma e se interessa) → SOM (quantos dá
para alcançar em 24–36 meses). Sempre com fonte.

**Risco do nicho** (vídeo 17): seguro (história, animais, finanças, mistério, melhora pessoal) · cinza (cripto,
apostas) · perigo (espinhas, fake news, notícia, política).

**Calculadora** (vídeos 16 e 20): views × RPM do nicho/idioma ÷ nº de vídeos = ganho estimado por vídeo.
